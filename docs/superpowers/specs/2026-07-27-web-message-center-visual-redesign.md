# Web 消息中心视觉改版设计

## 目标

将现有 Web 消息中心改造成适合交易所前台的深色独立页面：采用 Aster 式左侧分类与扁平消息列表，并保留 Apex 式右侧详情抽屉。App 页面、消息数据结构、分类映射及已读逻辑不在本次改动范围内。

## 页面结构

1. 顶部平台导航
   - 展示 ForX Finance 品牌及“交易、行情、资产、奖励、更多”等平台入口。
   - 右侧保留语言、通知和用户入口的静态展示。
2. 消息中心主体
   - 最大内容宽度为 1320px，居中展示。
   - 页面标题为“消息中心”，右侧提供搜索、只看未读、全部已读。
3. 左侧分类
   - 固定宽度约 220px。
   - 一级分类为：全部、公告、交易、资产、安全与风控、活动与奖励。
   - 当前分类以深灰背景和白色文字高亮。
   - 二级主题在选中一级分类后显示在分类下方。
4. 消息列表
   - 使用无卡片、细分割线的扁平列表。
   - 每条消息展示分类与主题、风险等级、标题、摘要、时间和未读点。
   - 不展示消息 Logo 或分类图标。
   - 重要和紧急消息通过文字标签与颜色强调，不使用大面积彩色背景。
5. 消息详情
   - 点击消息后从右侧打开 480px 宽的详情抽屉。
   - 抽屉展示分类、主题、时间、标题、摘要、风险提示、正文和跳转按钮。
   - 点击遮罩或关闭按钮返回列表，列表筛选状态保持不变。

## 视觉规范

- 页面背景：`#0b0b0d`
- 顶部导航与左侧分类背景：`#08090a` / `#101113`
- 分割线：`rgba(255,255,255,.08)`
- 主文字：`#f4f4f2`
- 次级文字：`#858783`
- 品牌强调色：`#69f0a0`
- 重要：`#e6a85e`
- 紧急：`#ff626f`
- 圆角只用于搜索框、按钮和详情抽屉，不给消息列表使用大卡片圆角。

## 交互与状态

- 搜索同时匹配标题与摘要。
- “只看未读”与分类、主题筛选可以叠加。
- “全部已读”更新列表未读点和顶部未读数量。
- 页面通过 `group` 与 `message` 查询参数支持生成静态预览状态。
- 无结果时在列表区域展示空状态文案。

## 响应式

- 大于等于 900px：左侧分类 + 右侧列表。
- 小于 900px：分类改为横向滚动，消息列表占满内容宽度。
- 小于 640px：详情抽屉占满屏幕，顶部工具区纵向排列。

## 验收标准

- Web 页面不再显示旧版产品侧栏和右侧消息概览。
- 页面整体结构与 Aster 独立公告页一致，详情交互与 Apex 右侧抽屉一致。
- 现有一级分类、二级主题、搜索、未读筛选、全部已读和详情功能均可继续使用。
- App HTML 不因 Web 改版发生视觉变化。
