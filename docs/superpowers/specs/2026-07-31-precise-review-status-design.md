# 精确审核状态展示设计

## 目标

模板和消息任务的主状态保持稳定的生命周期含义，由“当前节点”显示“内容审核中”或“多语言审核中”，让操作者能直接判断下一步由谁处理。

## 状态口径

- 模板生命周期和前端“状态”列只保留：草稿、审核中、驳回、已发布。
- 当前节点为 `content_review` 时，“当前节点”显示“内容审核中”。
- 当前节点为 `translation_creating` 或 `localization_review` 时，“当前节点”分别显示“多语言任务创建中”和“多语言审核中”。
- “当前节点”字段同步使用“内容审核中”“多语言任务创建中”“多语言审核中”等精确文案。

## 影响范围

- 人工消息模板列表、事件消息模板列表。
- 模板只读详情。
- 人工消息任务列表与任务详情中的当前节点。
- 多语言流程抽屉中的当前节点。
- 状态标签颜色：内容审核中为橙色，多语言审核中为紫色。

## 数据与兼容性

页面加载时以 `workflowStage` 校正旧持久化数据中的模板生命周期状态，避免“已发布节点 + 审核中状态”等冲突。状态筛选仍使用四状态模型，当前节点单独展示真实处理阶段。
