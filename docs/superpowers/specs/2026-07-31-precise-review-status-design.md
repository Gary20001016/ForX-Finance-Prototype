# 精确审核状态展示设计

## 目标

模板和消息任务进入审核流程后，不再统一显示含义模糊的“审核中”。前端根据当前流程节点显示“内容审核中”或“多语言审核中”，让操作者能直接判断下一步由谁处理。

## 状态口径

- 底层模板生命周期仍只保留：草稿、审核中、驳回、已发布。
- 当前节点为 `content_review` 时，前端主状态显示“内容审核中”。
- 当前节点为 `translation_creating` 或 `localization_review` 时，前端主状态显示“多语言审核中”。
- 其他生命周期状态仍显示草稿、驳回、已发布。
- “当前节点”字段同步使用“内容审核中”“多语言任务创建中”“多语言审核中”等精确文案。

## 影响范围

- 人工消息模板列表、事件消息模板列表。
- 模板只读详情。
- 人工消息任务列表与任务详情中的当前节点。
- 多语言流程抽屉中的当前节点。
- 状态标签颜色：内容审核中为橙色，多语言审核中为紫色。

## 数据与兼容性

不修改持久化状态、筛选条件或已有模拟数据，只增加统一的展示状态计算函数。因此既保持四状态模型兼容，又能向操作者展示真实处理阶段。
