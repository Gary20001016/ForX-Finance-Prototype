# ForX Finance 邮件正文样式设计

## 1. 目标

提供可复用的事务通知与活动营销两类邮件正文。两类邮件共用品牌、响应式容器与页脚，以兼顾可信度、可读性和主流邮件客户端兼容性。

## 2. 共用规范

- 外层背景：`#F5F7FA`；内容卡片宽度 600px，移动端宽度 100%。
- 正文使用系统字体；正文 14px / 1.7 行高；文字色 `#1D2129`。
- 品牌色：`#165DFF`；仅使用一个主行动按钮。
- 采用表格布局与内联 CSS；不依赖 JavaScript、外部 CSS、复杂定位或背景视频。
- 所有图片都提供 `alt`，按钮同时提供纯文本链接；营销邮件页脚包含退订入口。
- 每封邮件均有：品牌栏、正文、帮助联系方式与风险/版权页脚。

## 3. 事务通知样式

适用充值、提现、订单成交、安全和风控通知。

- 顶部为简洁品牌栏，正文标题直接说明业务结果。
- 用状态徽标表达成功、处理中、失败或风险预警。
- 关键数据放在两列表格：金额、币种、时间、交易对、网络或订单号。
- 高风险/失败状态使用浅红提示卡；成功使用浅绿提示卡。
- 只保留一个“查看详情”按钮，不使用营销 Banner、倒计时或多重 CTA。
- 页脚不包含营销退订；可包含风险提示、官方渠道和客服邮箱。

## 4. 活动营销样式

适用活动、奖励、会员权益与运营召回。

- 使用品牌色头图或渐变标题区，突出活动名称和利益点。
- 正文顺序固定为：活动说明、核心权益、参与按钮、活动规则/有效期。
- 可使用权益卡片和一个强调色数字，但移动端必须单列展示。
- 主按钮指向已备案活动页，页脚必须有退订链接及偏好设置入口。
- 不将充值、提现、安全、订单和风控消息使用为营销样式。

## 5. 模板参数

两类 HTML 模板统一预留：`{{ user_nickname }}`、`{{ amount }}`、`{{ currency }}`、`{{ occurred_at }}`、`{{ action_url }}`、`{{ support_email }}`。

事务模板可增加 `{{ detail_rows }}` 作为关键数据表格的预渲染行；营销模板可增加 `{{ campaign_name }}`、`{{ benefit }}`、`{{ expires_at }}`、`{{ unsubscribe_url }}`。

## 6. 验收

1. 两份 HTML 在桌面与移动端宽度下正文不横向溢出。
2. 关闭图片或不支持 HTML 时，标题、关键信息和主链接仍可理解。
3. 事务通知与营销邮件的 CTA、页脚和退订规则符合各自场景。
4. 模板变量采用 `{{ variable_name }}` 形式，未替换变量可在发送前校验。
