## 统一产品边界

- 当前仓库交付前端交互原型，使用模拟数据，不连接生产接口。
- 产品正式渠道为 Web / App 共用站内信、独立 App Push 和 Email；三种渠道均纳入生产验收。
- Email 同时支持事务邮件与营销邮件，多语言、变量、审核、发送记录和分析均复用消息中心主链路；真实服务商调用必须位于后台适配层。
- 短信、自动化旅程和高级营销归因不在当前范围。
- 人工消息任务与事件自动化完全分开。事件自动化由事件目录、事件通知规则、规则内容版本、触发记录和渠道发送记录组成。
- 内容版本发布采用原子切换，规则不中断；幂等键不包含内容版本。

## 变更规则

- 修改详细功能时，只更新归属模块，并检查引用该模块的总览或其他模块。
- 修改跨模块流程、产品范围、版本或关键指标时，同时更新 [消息中心总览](./00-消息中心总览.md)。
- 新增字段必须说明类型、必填性、来源、校验和脱敏要求。
- 新增状态必须同步状态流、允许操作、异常处理和验收标准。
