# App 消息中心视觉重设计

## 范围

只修改 `html/message-center-app.html` 的视觉布局与组件样式，不修改后台七类消息到前台五个分组的映射，也不修改分类筛选、主题筛选、只看未读、全部已读和消息详情交互。

## 视觉语言

- 使用纯黑背景，不使用蓝色渐变背景。
- 文字以高对比度白色和低对比度灰色组成。
- 荧光绿色是唯一的品牌强调色，用于选中状态、未读状态和主要操作。
- 重要和紧急风险分别保留橙色和红色语义色。
- 页面主体去卡片化，使用细分隔线划分消息。
- 减少圆角、阴影、描边和大面积色块。

## 页面结构

1. 顶部保留系统状态栏。
2. 标题栏展示返回、消息中心和全部已读。
3. 一级分类使用横向大字号文字 Tab。
4. 二级主题使用紧凑文字筛选，选中项显示绿色下划线。
5. 只看未读作为独立开关放在主题筛选右侧。
6. 紧急消息使用红色侧边线和简短风险说明。
7. 消息列表使用连续行和细分隔线，不使用独立卡片。
8. 底部导航使用低对比度线性图标，消息入口为绿色选中状态。
9. 消息详情使用纯黑底部面板和绿色主要操作按钮。

## 消息行

消息行显示分组、主题、风险、标题、摘要、时间和未读状态。列表处于“全部”时显示前台分组，进入具体分组后只显示主题。未读消息标题加粗并显示绿色圆点。

## 验收

- 页面整体观感与参考图一致：纯黑、扁平、绿色强调、密度更高。
- 所有现有筛选和详情交互继续可用。
- 文件仍是无外部依赖的独立 HTML。
- Web HTML 不发生变化。
