# 取消邮件类型设计

## 决策

后台不再展示或保存“事务邮件 / 营销邮件”业务类型。运营人员独立组合发件人身份、回复方式、正文格式、退订入口和追踪能力。

邮件服务商仍需要隔离发送信誉池，但发送流由预配置的发件人身份自动映射，运营人员不直接选择。

## 配置字段

- 发件人身份：从已认证身份中选择；身份内部包含邮箱地址与服务商发送流。
- 回复方式：`不接收回复`或`指定回复邮箱`。
- 回复邮箱：仅在指定回复邮箱时必填。
- 正文格式：纯文本或按语言上传 HTML 文件。
- 退订入口：独立开关；开启时必须提供退订文案，HTML 必须包含 `{{ unsubscribe_url }}`。
- 打开/点击追踪：独立开关。

## 校验规则

- 未选择有效发件人身份时禁止提交。
- 指定回复邮箱但未填写地址时禁止提交。
- 开启退订但未提供退订文案时禁止提交。
- HTML 邮件开启退订但缺少退订变量时阻断上传。
- 发件人身份决定底层 `transactional` 或 `broadcast` 发送流，不新增运营字段。

## 页面表现

- 编辑器移除“邮件类型”。
- 预览头部不再展示“事务邮件 / 营销邮件”，改为展示回复状态与正文格式。
- 纯文本兼容内容保持折叠展示。
- 审核与多语言预览复用同一配置和校验规则。
